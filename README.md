# 今日まで、生きてきた。

今日まで生きてきた日々を数え、命の時間に目を向けるための小さなWebサイトです。

生まれた日を設定すると、その日を1日目として今日までの日数を表示します。数字を通して、「今日まで、こんなに生きてきた」と感じるきっかけをつくります。

## 使い方

1. サイトを開き、生まれた日を年・月・日で入力します。
2. 「この日付で設定」を押すと、今日までの日数が表示されます。
3. 日付を変更する場合は、画面右上の「日付設定」から変更できます。

入力した日付はブラウザ内に保存されるため、次回も設定を引き継ぎます。ブラウザの保存データを削除すると、設定した日付も消去されます。

## 公開方法

このサイトはHTMLファイル1つで動作します。ビルドや外部ライブラリは不要です。

- `index.html` をブラウザで開く
- または GitHub Pages などの静的ホスティングに配置する

## 日数の数え方

- 設定した日を「1日目」として数えます。
- 今日の日付は、利用している端末のローカル日付を使います。
- 存在しない日付や未来の日付は設定できません。
- 暦日を基準に計算するため、時刻やタイムゾーンによる日数のずれを避けます。

## プライバシー

生まれた日はブラウザの `localStorage` に保存され、外部サーバーには送信されません。別のブラウザや端末とは共有されません。
